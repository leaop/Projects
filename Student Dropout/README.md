# Student Persistence & Dropout Analytics in Brazilian Higher Education

## Project Overview

This project analyzes student persistence and dropout patterns in Brazilian higher education using official INEP microdata enriched with socioeconomic indicators from IBGE.

## Main Business Question

How can higher education data be used to identify patterns associated with student persistence and dropout, and support more targeted retention strategies?

## Data Sources

- INEP — Higher Education Census
- IBGE — Socioeconomic indicators

## Project Status

Project setup and data source validation.
